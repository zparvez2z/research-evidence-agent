# Evaluation Protocol

All data in these notes is synthetic and exists only for this demonstration.

All F1 values use the same held-out evaluation set. Local-model latency was
measured locally. API latency includes network and provider overhead, so it
should be compared cautiously with local-model latency.

Energy consumption and monetary training cost were not measured.
